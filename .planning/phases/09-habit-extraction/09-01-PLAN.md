  <files>backend/app/schemas/habit.py</files>
  <action>
Create Pydantic v2 schemas for habit extraction API contracts:

1. **HabitSuggestion** - A single habit suggestion from Claude:
   - `title: str` - Field(min_length=5, max_length=100) - Short, actionable title
   - `description: str` - Field(max_length=300) - Why this habit matters
   - `suggested_frequency: Literal["daily", "3x_weekly", "weekly"]` - Suggested frequency

2. **HabitExtractionResponse** - Response from extraction endpoint:
   - `video_id: UUID` - Video the habits were extracted from
   - `suggestions: List[HabitSuggestion]` - 1-3 habit suggestions

3. **HabitCreateRequest** - Request to create a habit:
   - `video_id: UUID` - Source video
   - `title: str` - Field(min_length=1, max_length=200) - Habit title
   - `frequency: Literal["daily", "3x_weekly", "weekly"]` - Chosen frequency

4. **HabitResponse** - Full habit response:
   - `id: UUID`
   - `video_id: Optional[UUID]`
   - `title: str`
   - `frequency: str`
   - `current_streak: int`
   - `longest_streak: int`
   - `created_at: datetime`

Use existing patterns from `backend/app/schemas/summary.py`.
Export all schemas in module docstring for clarity.

3. **System prompt** (critical for quality habits):
   ```
   You are a habit extraction assistant. Your task is to identify 1-3 concrete, recurring habits from video transcripts.

   Extract habits that are:
   1. SPECIFIC: Concrete actions with clear completion criteria (e.g., "Do 20 pushups" not "exercise more")
   2. RECURRING: Can be done daily, 3 times weekly, or weekly as a sustainable practice
   3. DERIVED: Directly based on advice/techniques from the video content
   4. ACTIONABLE: Phrased as verbs (e.g., "Write 3 gratitude items" not "Practice gratitude")

   For each habit:
   - title: Short, action-oriented title (5-100 chars)
   - description: Brief explanation of why this habit matters, referencing the video content
   - suggested_frequency: One of "daily", "3x_weekly", or "weekly" based on what makes sense

   If the video doesn't contain actionable recurring advice, return fewer habits (minimum 1).
   Never return generic self-help habits that aren't derived from the specific video content.
   ```
