  <files>backend/app/schemas/subscription.py, backend/app/api/v1/endpoints/subscriptions.py</files>
  <action>
1. Add to backend/app/schemas/subscription.py:
```python
from datetime import date
from pydantic import BaseModel

class UsageResponse(BaseModel):
    videos_used: int
    videos_limit: int  # -1 for unlimited (Pro)
    reset_date: date
    is_pro: bool
    can_create_video: bool
```

2. Add to backend/app/api/v1/endpoints/subscriptions.py:
- GET /usage endpoint (requires auth via get_current_user)
- Check if usage_reset_date is in previous month, reset videos_this_month to 0 if so
- Set usage_reset_date to first of current month
- Commit changes after reset check
- Return UsageResponse with:
  - videos_used = user.videos_this_month
  - videos_limit = -1 if Pro, else 10
  - reset_date = user.usage_reset_date or today.replace(day=1)
  - is_pro = user.subscription_tier == "pro"
  - can_create_video = is_pro or videos_used < 10

Use date.today() and check if usage_reset_date.month != today.month for reset logic.
  </action>
  <verify>Run `curl -X GET http://localhost:8000/api/v1/usage -H "Authorization: Bearer {token}"` returns usage JSON</verify>
  <done>GET /usage returns current usage status with reset logic</done>
</task>
