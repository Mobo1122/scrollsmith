<task type="auto">
  <name>Task 3: Add idempotency check for webhook events</name>
  <files>backend/app/api/v1/endpoints/subscriptions.py</files>
  <action>
Add simple idempotency using in-memory set (production would use Redis/DB):

1. Create module-level set: _processed_events: set[str] = set()
2. Before processing, check if event_id in _processed_events
3. If yes, return {"status": "already_processed"}
4. After successful processing, add event_id to set

Note: For v1, in-memory is acceptable. Production would use Redis with TTL or database table.
Log when skipping duplicate: logger.info(f"Skipping duplicate event {event_id}")
  </action>
  <verify>Send same event twice, second returns "already_processed"</verify>
  <done>Duplicate webhook events are handled idempotently</done>
