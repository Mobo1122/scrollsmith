Create four ORM models following the minimal Phase 1 schema from research:

1. Create `backend/app/models/user.py`:
   - id: UUID primary key (use uuid.uuid4 as default)
   - email: String(255), unique, nullable=False
   - password_hash: String(255), nullable=True (for email/password auth)
   - apple_id: String(255), unique, nullable=True (for Apple Sign In)
   - subscription_tier: String(50), default="free" (free/pro)
   - created_at: DateTime with timezone, default=func.now()
   - updated_at: DateTime with timezone, onupdate=func.now()
   - Use SQLAlchemy 2.0 declarative syntax

2. Create `backend/app/models/playbook.py`:
   - id: UUID primary key
   - user_id: UUID, ForeignKey("users.id", ondelete="CASCADE")
   - name: String(100), nullable=False
   - icon: String(50), nullable=True (emoji or icon name)
   - created_at: DateTime
   - relationship("User", back_populates="playbooks")
   - relationship("Video", back_populates="playbook")

3. Create `backend/app/models/video.py`:
   - id: UUID primary key
   - user_id: UUID, ForeignKey("users.id", ondelete="CASCADE")
   - playbook_id: UUID, ForeignKey("playbooks.id", ondelete="SET NULL"), nullable=True
   - source_url: String(500), nullable=True (TikTok/IG/YouTube URL, null for camera uploads)
   - transcript: Text, nullable=True
   - summary_bullets: Text, nullable=True (JSON string for now, phase 5 will populate)
   - tags: ARRAY(String), nullable=True (PostgreSQL array type)
   - created_at: DateTime
   - relationships to User, Playbook, Habit

4. Create `backend/app/models/habit.py`:
   - id: UUID primary key
   - user_id: UUID, ForeignKey("users.id", ondelete="CASCADE")
   - video_id: UUID, ForeignKey("videos.id", ondelete="SET NULL"), nullable=True
   - title: String(200), nullable=False
   - frequency: String(50) (daily/3xweekly/weekly)
   - current_streak: Integer, default=0
   - longest_streak: Integer, default=0
   - created_at: DateTime
   - relationship("User", "Video")

5. Import all models in `backend/app/models/__init__.py` for easy access

6. Initialize Alembic with async template:
   - Run `alembic init -t async alembic`
   - Update `alembic/env.py` to import all models: `from app.models import user, video, habit, playbook`
   - Set target_metadata = Base.metadata (from database.py)
   - Configure async engine in run_migrations_online

7. Create first migration:
   - Run `alembic revision --autogenerate -m "Initial schema: users, videos, habits, playbooks"`
   - Review generated migration for correctness

Why: Matches schema design from research, uses UUID for all IDs (better for distributed systems), includes proper foreign keys and indexes, sets up async Alembic for future migrations.
