**Part A: Create RootNavigationView.swift**

Create `ios/Scrollsmith/Views/Navigation/RootNavigationView.swift` following RESEARCH.md Pattern 3.

Requirements:
- `@State private var navigationModel = NavigationModel()`
- `@Environment(\.horizontalSizeClass) private var horizontalSizeClass` (for potential size-specific adjustments)
- Use two-column NavigationSplitView:
  ```swift
  NavigationSplitView(
      columnVisibility: $navigationModel.columnVisibility,
      preferredCompactColumn: .constant(.detail)  // iPhone starts on detail (Library)
  ) {
      SidebarView(selection: $navigationModel.selectedSection)
  } detail: {
      detailContent
  }
  .navigationSplitViewStyle(.balanced)
  ```

- Create `@ViewBuilder private var detailContent: some View` that:
  - Wraps content in `NavigationStack(path: navigationModel.currentPath)`
  - Uses ZStack to prevent conditional view update issues (Pitfall 6)
  - Switches on `navigationModel.selectedSection`:
    - .library -> VideoGridView() with title "Library"
    - .types -> Placeholder Text("Types - Phase 15") with title "Types"
    - .playbooks -> PlaybookListView() with title "Playbooks"
      - NOTE: PlaybookListView already has its own NavigationStack. We need to extract its content without the outer NavigationStack. For now, use it as-is and accept nested NavigationStack (will refactor in Phase 15 if needed).
    - .tags -> Placeholder Text("Tags - Phase 15") with title "Tags"
    - .trash -> Placeholder Text("Trash - Phase 15") with title "Trash"
    - nil -> ContentUnavailableView("Select a Section", systemImage: "sidebar.left", description: Text("Choose from the sidebar"))

  - Add `.navigationDestination(for: VideoDTO.self)` for video drill-down to SummaryDisplayView
  - Add `.navigationDestination(for: PlaybookDTO.self)` for playbook drill-down to PlaybookDetailView

- Pass through environment objects that MainTabView received:
  - AuthViewModel (from ContentView)
  - SubscriptionViewModel (from app)
  - UploadQueueService (from app)
